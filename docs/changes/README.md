# Change log index

This directory contains change records for the portfolio. Each record links a change brief to its implementation, release, and postmortem (if any).

## Record format

Change records are named `YYYY-MM-DD-slug.md` and use the change record template at `docs/templates/change-brief.md`.

## Current records

No change records have been created yet. The documentation system rollout itself is tracked through the work package plan and the gap task list, not through individual change records.

## What this index does not claim

- That change records exist for past work (they do not; this system is being introduced).
- That all future changes will have records (high-risk changes will; low-risk changes may not).
